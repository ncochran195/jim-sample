# Mark a task done, or reopen it

**Purpose:** press a task's toggle button on its project's page.

**Inputs:** `page`; `action`, `"Mark done"` or `"Reopen"`; `title`, the task's exact title.

**Outputs:** none. The page ends on the project's page, reloaded.

**Preconditions:** signed in, on the project's page, with the task in the state the action expects.

**Flakiness:** none.
